# Workflow

## Rules
1. Every source change must produce a ROM matching `tests/expected.json` (CI checks this on every push/PR).
2. Structural changes (moving or splitting files, replacing addresses with labels) are done with scripts
   (`tools/migration/`) and committed separately from semantic changes.
3. Naming and documentation changes must not alter the generated bytes.

## Local build
Requires asar 1.91 (`asar.exe` on Windows). Provide its path via `--asar`, the `ASAR` variable, or place it in `tools/bin/`.
`tools/build.py` creates the output file as 2 MB of zeros, runs asar with `-werror --no-title-check --fix-checksum=off`
and verifies the hashes. Diagnosing a mismatch: `python tools/verify.py build/HarvestMoon.sfc --rom original.sfc`.

## CI (`.github/workflows/build.yml`)
Builds asar from source (tag `v1.91`, cached), assembles the US ROM, compares size/CRC32/MD5/SHA-1 and exposes
the result in run annotations and as the `HarvestMoon-US` artifact.

## Asset converters (`tools/gfx/`)
- `palette.py` — palettes ($A8/$A9): `extract` (from the old `db` sources), `pack` (JSON -> `.pal`), `emit-asm`, `check`.
  The source of truth is `assets/gfx/palettes/*.json` (edit colours as `#RRGGBB`), packed into `*.pal` files that the
  assembler includes with `incbin`. CI runs `palette.py check` before the build.
- Editing a palette: change the JSON, run `python tools/gfx/palette.py pack`, commit both files. The ROM hash will of
  course change after an intentional edit; update `tests/expected.json` only for deliberate modifications.
- `tilemap_codec.py` — LZSS codec for the compressed tilemap/charactermap blobs (see `docs/formats/tilemap-compression.md`).
- `tiles.py` — raw 2/4/8bpp SNES tile data <-> indexed PNG sheets (`to-png`, `from-png`), lossless for any data.
- `dialogs/dialog.py` — dialog word streams <-> editable text (`assets/dialogs/<region>/`), all regions.
- `maps/objmap.py` — object maps (bank $A7) <-> JSON grids in `assets/maps/`; widths in `tools/maps/map_dims.json`.
- `data/bankbin.py` — sprite, tile, character and audio banks: one `.bin` per label in `assets/`, included with `incbin` (labels unchanged).
- `gfx/gfxpipe.py` — export compressed blobs to raw/PNG, re-import edited PNG (recompress, size must stay equal), verify exact re-encode.
