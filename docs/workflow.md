# Workflow

## Rules
1. Every source change must produce a ROM matching `tests/expected.json` (CI checks this on every push/PR).
2. Structural changes (moving or splitting files, replacing addresses with labels) are done with scripts
   (`tools/migration/`) and committed separately from semantic changes.
3. Naming and documentation changes must not alter the generated bytes.

## Local build
Requires asar 1.91 (`asar.exe` on Windows). Build it with `python tools/build_asar.py` (submodule `third_party/asar`, see [building.md](building.md)), or provide a path via `--asar`, the `ASAR` variable, or place it in `tools/bin/`.
`tools/build.py` creates the output file as 2 MB of zeros, runs asar with `-werror --no-title-check --fix-checksum=off`
and verifies the hashes. Diagnosing a mismatch: `python tools/verify.py build/HarvestMoon.sfc --rom original.sfc`.

## Regional builds (complete ROMs)
`python3 tools/build.py --region EU|DE|JP --out build/HarvestMoonXX.sfc` assembles the same sources with `-DREGION_xx=1` and
builds the complete ROM and verifies size/CRC32/MD5/SHA-1 against `tests/expected.json` (keys `EU`, `DE`, `JP`). Graphics, fonts,
palettes and dialogs of the release come from the per-release assets (`docs/regions.md`, "Regional data banks"); `tools/build_assets.py` generates all of them.
A change in a shared (non-patch) line is checked against all regions; keep `+!RAM_SHIFT` on hex literals that point into WRAM above `$08D1` and prefer label names for code pointers.
Region switch and RAM layout: `src/common/region.asm`, details in `docs/regions.md`.
Tools: `tools/analysis/align_regions.py` (coverage report, `--md docs/regions.md`), `tools/analysis/disasm65816.py`,
`tools/migration/region_patch.py` (regenerates all patch blocks from the ROM dumps: `--eu --de --jp`, ROMs are tool inputs only;
`--write-expected` stores the full-ROM hashes). After editing US code that is inside a patch block, edit the `else` branch (US text) and
check all regions; regenerating with the tool is also possible (it starts from the US text).

## Audio preview (`.github/workflows/audio.yml`)

Rendering SPC and MP3 copies of all songs and sound effects is slow, so it is not part of the ROM build. The separate
`audio-preview` workflow runs only when `assets/audio/**` or `tools/audio/**` change (or by hand via *Run workflow*, with an
optional length in seconds) and publishes the result as the `HarvestMoon-audio-listen` artifact (14 days, never committed).
Locally: `python3 tools/audio/audioconv.py spc --all --out build/listen/spc`, then `audioconv.py render build/listen/spc --format mp3`.

## CI (`.github/workflows/build.yml`)
Builds asar from the `third_party/asar` submodule (tag `v1.91`, cached), assembles the US ROM, compares size/CRC32/MD5/SHA-1 and exposes
the result in run annotations and as the `HarvestMoon-US` artifact.

## Tests of the graphics pipeline
`python3 tests/test_pngsync.py` runs in about 90 s (quick checks that skip the bit-exact rebuild, the round trip only for eu/de/jp).
The full version (every scenario with the bit-exact rebuild, width and screen audits, US round trip, refusal checks) takes about 2.5 min:
`HM_FULL_TESTS=1 python3 tests/test_pngsync.py`. CI runs the default version; run the full one before changing `composed.py` or `pngsync.py`.

## Asset converters (`tools/gfx/`)
- `palette.py` — palettes ($A8/$A9): `extract` (from the old `db` sources), `pack` (JSON -> `.pal`), `emit-asm`, `check`.
  The source of truth is `assets/gfx/palettes/*.json` (edit colours as `#RRGGBB`), packed into `*.pal` files that the
  assembler includes with `incbin`. CI runs `palette.py check` before the build.
- Editing a palette: change the JSON, run `python tools/gfx/palette.py pack`, commit both files. The ROM hash will of
  course change after an intentional edit; update `tests/expected.json` only for deliberate modifications.
- `tilemap_codec.py` — LZSS codec for the compressed tilemap/charactermap blobs (see `docs/formats/tilemap-compression.md`).
- `tiles.py` — reference implementation of raw 2/4/8bpp SNES tile data <-> indexed PNG sheets (`to-png`, `from-png`), lossless for any data.
- `dialogs/dialog.py` — dialog texts (`assets/dialogs/<region>/bank_XX.txt`, the only source) -> generated `build/gen/dialogs/<region>/bank_XX.asm` (`build`), `check`; all regions.
- `maps/objmap.py` — object maps (bank $A7): the JSON grids in `assets/maps/` are the only source; `build` writes `build/gen/maps/bank_A7.asm`, `check [--rom]`, `extract --rom`; widths in `tools/maps/map_dims.json`.
- `build_assets.py` — also writes the generated assembly (`build/gen/{dialogs,objects,maps}/`); generates every `incbin`'d binary that has an editable source (`assets/gfx/palettes/*.pal`, `assets/gfx/{tiles,sprites,characters}/*.bin` incl. the font tables) from the PNG/text/JSON sources; run by `tools/build.py` before asar. These generated files are git-ignored; run `python3 tools/build_assets.py` by hand before the checks/tests that read them.
- `ai/aidata.py` — AI script banks ($B3-$B5): `assets/ai/scripts.json` + `assets/ai/npc_sprite_tables.txt` -> `build/gen/ai/{head_BX,slots_NN}.asm` (`build`), `check`; the script DSL bodies stay in `src/ai/`.
- `maps/areadata.py` — per-area tables (graphics descriptors, transitions, object maps/properties, music sets): `assets/areas/` -> `build/gen/maps/*.asm` (`build`), `check`; format `docs/formats/area-data.md`.
- `data/smalltables.py` — generic small tables: `assets/tables/*.json` -> `build/gen/tables/*.asm` (`build`), `check`; `menu/nameinput.py` — name entry grids (`assets/menu/name_input.txt`); `dialogs/texttables.py` — dialog engine tables per release; formats `docs/formats/menu-data.md`, `dialog-tables.md`.
- `data/tabledata.py` — typed data tables of the code banks: `assets/tables/data/*.csv` (named columns) -> `build/gen/blocks/*.asm` (`build`), `check`, `rows_of()` for tools; `gfx/presets.py` — `assets/gfx/presets.csv` -> `Table_<REG>_Presets`; format `docs/formats/data-tables.md`.
- `data/regionbanks.py` — blob level inventory of the regional data banks (which blob of EU/DE/JP is region specific); `analysis/region_diff.py --data-ranges` lists the differing byte ranges.
- `data/gfxbanks.py` — graphics banks ($88-$A9): `assets/gfx/banks.json` (ORG, blobs in ROM order, regional `*` marker, padding) -> generated `build/gen/gfx/<kind>/bank_XX.asm` (`build`), `check` (every bank is $8000 bytes); `src/main.asm` includes the generated files.
- `data/bankbin.py` — only the `BANK` constant for the tests now; the audio banks are generated by `audio/audioconv.py build` (`assets/audio/banks.json` -> `build/gen/audio/bank_XX.asm`).
- `gfx/pngsync.py` — **graphics sources**: composed images `assets/gfx/png/frames/obj_XXXX_<Name>/f_PPPP.png` (object animation frames), `assets/gfx/png/screens/*.png` (name tables rendered with their tiles) and remainder sheets `assets/gfx/png/{tiles,sprites}/<label>.png` (pixels no image shows) plus `assets/gfx/tilemaps/<label>.map.txt`
  (BG name tables; `<label>.json` sidecars) are the source of truth for all 151 graphic blobs; `import` splits edited images back into tiles / sprite blocks (shared tiles re-render all images, contradicting edits are errors); `export` / `check` / `preview`, and `sheet` (renders whole sheets into `build/gfx_sheets/` for viewing). `composed.py` holds the image <-> tile logic.
  `build` writes the (git-ignored) `assets/gfx/{tiles,sprites,characters}/*.bin` that the assembler includes from the sources, `import` re-encodes edited sources and updates sidecar/padding (a longer compressed stream needs `--allow-resize`),
  `--region eu|de|jp` (export/build/import/check) handles the blobs that differ from US (`assets/gfx/png/<region>/`, `assets/gfx/tilemaps/<region>/`, generated `.bin` in `assets/gfx/{tiles,characters}/<region>/`), `build --region all` is what `build_assets.py` runs;
  `check` asserts that the sources rebuild to the generated `.bin`; the ROM hash check in CI proves they equal the original ROM data. Modder workflow, constraints and what is not convertible yet: `docs/formats/graphics-png.md`.
- `gfx/gfxpipe.py` — older low-level helper (raw export, exact re-encode `verify`); superseded by `pngsync.py` for editing.
- `fonts/font.py` — font glyphs: one 16x16 2bpp indexed PNG per glyph in `assets/fonts/<region>/glyph_XXXX.png`
  (id = dialog word, `glyphs.json` maps ids to characters). Edit a PNG (pixel value = SNES colour index: 0/1 baked background
  dither, 2/3 letter), run `python tools/fonts/font.py build --region us --write-assets` to regenerate the
  `assets/gfx/tiles/sFontGlyphs_*.bin` tables included by the ROM, then `font.py seal` to refresh the recorded hashes. Format: `docs/formats/font.md`.
- `objects/objdata.py` — banks $86/$87 object animation data: sources `assets/objects/bank_8x/` (`bank.json`, `objects/NNNN.json`, `frames.txt`) -> `build/gen/objects/bank_8x.asm` (`build`), `check [--rom]`, `extract --rom`, `analyze`; format: `docs/formats/object-data.md`.
- `audio/spc700.py`, `audio/audio_map.py` — SPC700 disassembler and audio blob map; the audio system is documented in `docs/audio.md`.
- `audio/audioconv.py` (`brr.py`, `trackfmt.py`, `spcasm.py`) — audio sources (WAV/JSON samples, text songs/SFX, SPC700 driver assembler) <-> blobs and tables, MIDI/WAV export; format and modding workflow in `docs/formats/audio-sources.md`.
